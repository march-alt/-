# 本のよりみち｜おすすめ本診断

ジャンルや気分、好きな作家・本、読みたい形式から、登録された本を探すシンプルなWebアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 読みたいジャンルや気分などを選び、「おすすめの本を探す」を押します。
3. 気になる本の「Amazonで探す」または「図書館で探す」から検索します。

## 公開方法

GitHub Pagesを使う場合は、リポジトリの **Settings → Pages** で、公開元を **Deploy from a branch**、ブランチを **main**、フォルダーを **/(root)** に設定します。リポジトリ直下の `index.html` がサイトのトップページになります。

## データについて

本の登録データは `index.html` に含まれています。サーバーや外部APIは使っていません。登録内容を更新した場合は、更新した `index.html` をリポジトリに反映してください。
